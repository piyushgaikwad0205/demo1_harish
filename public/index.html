REST API Reference & Documentation

All available pre-configured endpoints and request specifications

GET /api/health Returns server heartbeat, memory utilization, and system hardware metrics
GET /api/metrics Returns aggregate request statistics, average response latency, and hit counters
GET /api/users Lists users. Supports query params: ?search=, ?role=, ?status=
POST /api/users Creates a new user. Payload: { "name", "email", "role", "status" }
GET /api/users/:id Retrieves details for a specific user ID
PUT /api/users/:id Updates existing user attributes by ID
DELETE /api/users/:id Deletes user record by ID
GET /api/products Lists catalog items. Query params: ?category=, ?search=
POST /api/products Adds a catalog product. Payload: { "name", "category", "price", "stock" }
DELETE /api/products/:id Removes a product from catalog by ID
POST /api/echo Mirror endpoint returning back received headers, payload, and server timestamp
GET /api/logs Returns the latest intercepted HTTP request log array
